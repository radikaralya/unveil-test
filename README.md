# UNVEIL — «Ты носишь знак. Но какой — твой?»

Самостоятельный статический сайт: HTML, CSS и обычный JavaScript. Сборка, установка пакетов, аккаунт и серверная часть не нужны. Шрифты и изображения находятся в assets/; ответы никуда не отправляются. После обновления страницы прохождение начинается заново.

## Онлайн

Публичный тест: https://radikaralya.github.io/unveil-test/

Исходники: https://github.com/radikaralya/unveil-test

GitHub Pages публикует корень ветки main. После отправки изменений в main сайт обновляется автоматически.

## Открыть в VS Code

Выбери «Файл → Открыть папку» и укажи папку репозитория `unveil-test`.

## Запустить

Дважды нажми на `index.html`, чтобы открыть в обычном браузере. Можно открыть файл из проводника VS Code через «Показать в Finder». Тест работает через file://, так как использует обычные скрипты без fetch и ES-модулей.

Если нужен локальный HTTP-сервер: открой терминал VS Code в папке проекта и выполни `python3 -m http.server 8000`. Затем открой http://localhost:8000. Это необязательно.

## Где что менять

- `index.html` — вступление, структура экранов и ссылки возвращения в UNVEIL.
- `styles.css` — цвета, шрифты, анимация и адаптивная вёрстка.
- `content.js` — шесть вопросов, четыре ответа в каждом и описания результатов.
- `scoring.js` — подсчёт результата и разрешение ничьей.
- `app.js` — переключение экранов, выбор вариантов и навигация.
- `assets/` — изображения из проекта, Angst, Manrope и Cormorant Garamond.
- `tests.cjs` — проверка подсчёта и комплектности файлов.

В `content.js` исходный порядок вариантов имеет значение: 0 — анх, 1 — древо сефирот, 2 — гексаграмма, 3 — уроборос. При показе порядок переставляется; привязка к результатам сохраняется.

При равенстве очков побеждает ответ на шестой вопрос, если он относится к лидерам. Иначе учитывается пятый, четвёртый и так далее. Кнопка «Назад» сохраняет ответы; «Пройти ещё раз» полностью сбрасывает тест.

Результат — авторская интерпретация, а не диагностика и не традиционное толкование личности.

## Проверка

Если установлен Node.js: `node tests.cjs` (или `npm test`). Проверяются все 4096 сочетаний ответов, ничьи, некорректный ввод, тексты и наличие ресурсов.

Публичная страница проверена в браузере без авторизации: открытие, прохождение всех шести вопросов, выдача результата, сохранение ответа при возврате и повторное прохождение. Вёрстка предусматривает мобильную и настольную ширину, клавиатурное управление и уменьшение анимации через prefers-reduced-motion.

## Размещение в интернете

Сайт размещён на GitHub Pages. Его публичный адрес можно использовать в статье Дзена. Все ресурсы сохраняют текущие относительные пути. Тильда для работы теста не нужна.

Изображения и шрифты перенесены из существующего проекта UNVEIL; новые ИИ-изображения не использованы.
